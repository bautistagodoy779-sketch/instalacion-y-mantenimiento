04/03/2026 - Diagnóstico

El diagnóstico consiste en identificar correctamente la falla antes de intervenir un equipo informático.

  • Inspección visual.
  • Comprobación de alimentación.
  • Verificación del hardware.
  • Análisis del software.
  • Registro de resultados.

25/03/2026 - Sistema Operativo

El sistema operativo es el software principal de una computadora. Se encarga de administrar el hardware, ejecutar programas y permitir la interacción con el usuario.

Administración

Gestiona memoria, procesos y dispositivos.

Archivos

Organiza carpetas, documentos y unidades de almacenamiento.

Seguridad

Controla permisos de usuarios y protección del sistema.

Interfaz Gráfica

La interfaz gráfica permite utilizar la computadora mediante ventanas, iconos, botones y menús.

Elemento Función
Escritorio Área principal de trabajo.
Barra de tareas Acceso rápido a programas.
Menú Inicio Configuración y aplicaciones.
Explorador Administración de archivos.

Panel de Control

Permite modificar la configuración del sistema operativo.

  • Fecha y hora.
  • Redes.
  • Usuarios.
  • Programas.
  • Dispositivos.
  • Opciones de energía.

Herramientas del Sistema

Desfragmentador

Optimiza discos HDD reorganizando archivos.

Liberador de espacio

Elimina archivos temporales.

Restaurar sistema

Permite volver a un estado anterior del equipo.

Atajos de Teclado

Combinación Acción
Ctrl + C Copiar
Ctrl + V Pegar
Ctrl + X Cortar
Ctrl + Z Deshacer
Ctrl + A Seleccionar todo.
Alt + Tab Cambiar de ventana.
Windows + R Abrir Ejecutar.
Windows + E Abrir Explorador.

Resumen

El sistema operativo administra todos los recursos del equipo y proporciona una interfaz sencilla para que el usuario pueda trabajar de manera eficiente.

27/03/2026 - Microprocesador

El microprocesador (CPU) es el componente encargado de ejecutar instrucciones, realizar cálculos y coordinar el funcionamiento general del equipo. Se lo conoce como el cerebro de la computadora porque procesa toda la información que recibe del software y del hardware.

Características principales

Núcleos

Permiten ejecutar varias tareas simultáneamente aumentando el rendimiento.

Hilos

Cada núcleo puede gestionar uno o más procesos de manera paralela.

Frecuencia

Se mide en GHz e indica la velocidad de funcionamiento del procesador.

Concepto Descripción
Frecuencia Base Velocidad normal del procesador.
Turbo Boost Incremento automático de velocidad cuando es necesario.
Memoria Caché Memoria rápida utilizada para acelerar procesos.
Arquitectura Define el funcionamiento interno del procesador.

01/04/2026 - Placa Madre

La placa madre es el circuito principal del computador. Todos los componentes se conectan a ella para intercambiar información y recibir alimentación eléctrica.

Componentes

Elemento Función
Socket Instalación del procesador.
Chipset Comunicación entre CPU, RAM y periféricos.
Ranuras DIMM Instalación de memoria RAM.
PCI Express Conexión de tarjetas de expansión.
SATA Conexión de discos HDD y SSD.
M.2 Conexión de SSD NVMe de alta velocidad.

Batería CMOS

Mantiene almacenada la configuración del BIOS y conserva la fecha y hora del sistema cuando el equipo está apagado.

BIOS

Firmware que realiza la comprobación inicial del hardware y permite configurar el funcionamiento del equipo antes de cargar el sistema operativo.

Conectores principales

  • ATX 24 pines.
  • ATX CPU 4/8 pines.
  • CPU_FAN.
  • SYS_FAN.
  • USB internos.
  • Audio frontal.
  • SATA III.
  • M.2 NVMe.

Comparación de interfaces

Interfaz Velocidad aproximada

SATA III 6 Gb/s
PCI Express 3.0 Hasta 32 Gb/s
PCI Express 4.0 Hasta 64 Gb/s

Condensadores

Filtran y estabilizan la alimentación eléctrica.

Transistores

Controlan el flujo de corriente dentro de los circuitos.

Chipset

Coordina la comunicación entre todos los dispositivos.

Ergonomía

La ergonomía es la disciplina que adapta el puesto de trabajo a las capacidades físicas y cognitivas de las personas, buscando mayor comodidad, seguridad y eficiencia.

Objetivos

Seguridad

Reducir accidentes y lesiones laborales.

Comodidad

Mejorar la postura y disminuir el cansancio.

Productividad

Optimizar el rendimiento del trabajador.

Postura recomendada

Elemento Recomendación
Espalda Recta y apoyada en el respaldo.
Pies Totalmente apoyados sobre el piso.
Monitor A la altura de los ojos.
Brazos Ángulo aproximado de 90°.
Muñecas Posición neutra.

Iluminación

La iluminación se mide en Lux (lx). Una iluminación adecuada disminuye la fatiga visual y mejora el rendimiento.

Actividad Lux recomendados
Oficina 300 - 500 lx
Trabajo técnico 500 - 750 lx
Laboratorio 750 - 1000 lx

TME

Los Trastornos Musculoesqueléticos son lesiones producidas por movimientos repetitivos, malas posturas o esfuerzos prolongados.

  • Dolor cervical.
  • Dolor lumbar.
  • Tendinitis.
  • Síndrome del túnel carpiano.
  • Fatiga muscular.

Mantenimiento preventivo

El mantenimiento preventivo consiste en limpiar, revisar y optimizar el equipo antes de que aparezcan fallas, prolongando su vida útil y mejorando su rendimiento.

Pruebas de Estrés

Las pruebas de estrés permiten comprobar la estabilidad del hardware sometiéndolo a cargas de trabajo intensivas durante un tiempo determinado. Estas pruebas ayudan a detectar problemas de temperatura, alimentación o rendimiento antes de que se produzcan fallas durante el uso cotidiano.

Prime95

Utilizado para verificar la estabilidad del microprocesador y la memoria RAM mediante cálculos matemáticos complejos.

FurMark

Somete la tarjeta gráfica a una carga extrema para comprobar temperaturas y estabilidad.

HWMonitor

Monitorea temperaturas, voltajes y velocidad de los ventiladores en tiempo real.

Temperaturas recomendadas

Componente Temperatura recomendada
Procesador 30°C - 75°C
Tarjeta gráfica 35°C - 85°C
SSD 25°C - 60°C
Disco HDD 25°C - 50°C

Caso Práctico 2 - Ergonomía del Puesto de Trabajo

Evaluación del Puesto de Trabajo
Situación Se trabaja durante varias horas reparando notebooks en un puesto con iluminación deficiente y una silla sin apoyo lumbar.
Problemas detectados
  • Fatiga visual.
  • Dolor cervical.
  • Mala postura.
  • Mayor riesgo de TME.
Correcciones
  • Regular la altura de la mesa.
  • Utilizar silla ergonómica.
  • Mejorar la iluminación.
  • Realizar pausas activas.
Resultado Se mejora la comodidad, disminuye la fatiga y se reducen los riesgos musculoesqueléticos.

Caso Práctico 3 - Protocolo de seguridad para una prueba de estrés

Paso Acción Objetivo
1 Verificar la limpieza física interna del equipo. Comprobar que los ventiladores estén limpios y que la pasta térmica no esté seca. Garantizar una correcta refrigeración antes de comenzar la prueba.
2 Controlar que la temperatura ambiente sea adecuada y que el gabinete tenga buena circulación de aire. Evitar daños producidos por temperaturas extremas.
3 Abrir HWMonitor antes de ejecutar la prueba para monitorear las temperaturas en tiempo real. Poder detener inmediatamente la prueba si se detectan valores peligrosos.
Resultado esperado La prueba debe realizarse manteniendo las temperaturas dentro de valores seguros y sin producir apagados ni errores del sistema.

Caso Práctico 4 - Diagnóstico de Memoria RAM

Falla en la Memoria RAM
Situación Una computadora enciende, pero no muestra imagen y emite varios sonidos (beeps) durante el arranque.
Diagnóstico Los códigos sonoros indican una posible falla o mala conexión de la memoria RAM.
Procedimiento
  1. Apagar y desconectar el equipo.
  2. Abrir el gabinete.
  3. Retirar cuidadosamente los módulos de memoria.
  4. Limpiar los contactos con una goma blanca o alcohol isopropílico.
  5. Volver a instalar la memoria correctamente.
  6. Probar cada módulo por separado para identificar posibles fallas.
Herramientas Destornillador, pulsera antiestática, alcohol isopropílico y paño de microfibra.
Resultado El equipo inicia correctamente después de reinstalar la memoria RAM y verificar el funcionamiento de los módulos.
Conclusión Una mala conexión de la memoria RAM puede impedir el arranque del sistema. La limpieza y correcta instalación suelen resolver este tipo de inconvenientes.

Caso Práctico 5 - Instalación de un Disco SSD

Reemplazo de un Disco HDD por un SSD
Situación Una computadora tarda varios minutos en iniciar el sistema operativo y presenta un bajo rendimiento al abrir programas.
Diagnóstico Se comprueba que el disco rígido (HDD) presenta un funcionamiento lento debido al desgaste por el uso continuo.
Procedimiento
  1. Apagar y desconectar el equipo.
  2. Retirar el disco HDD.
  3. Instalar el nuevo SSD.
  4. Conectar el cable SATA y la alimentación.
  5. Instalar o clonar el sistema operativo.
  6. Comprobar el correcto funcionamiento.
Herramientas Destornillador Phillips, cable SATA, SSD y software de clonación (si corresponde).
Resultado El equipo inicia en pocos segundos y mejora notablemente la velocidad de carga del sistema operativo y de las aplicaciones.
Conclusión Reemplazar un HDD por un SSD mejora significativamente el rendimiento general de la computadora y reduce los tiempos de espera.
